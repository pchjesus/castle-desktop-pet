# Castle Desktop Pet

Windows 10/11용 캐슬 데스크톱 펫 v0.1 기반입니다. 현재 캐릭터 이미지는 임시 표시이며, 실제 아킬라 이미지와 애니메이션은 포함하지 않습니다.

## 개발

Node.js 22 이상을 설치한 뒤 저장소에서 실행합니다.

```sh
npm ci
npm run build
npm test
npm start
```

`npm start`는 빌드 후 Electron을 실행합니다. 캐릭터를 드래그해 이동하고 우클릭 메뉴에서 크기를 설정하거나 종료합니다. 창 위치는 Electron 사용자 데이터 디렉터리에 저장됩니다. `npm run dev`는 렌더러만 브라우저에서 확인하기 위한 Vite 서버입니다.

요구사항은 [제품 명세](docs/PRODUCT_SPEC.md)를 참조하세요.

## 오프라인 HTML 미리보기

`npm run preview:export`로 저장소 루트의 `preview.html`을 생성합니다. 파일을 브라우저에서 직접 열면 서버와 인터넷 없이 크기, 상태, 대사와 드래그를 확인할 수 있습니다. 이는 Windows 창 동작을 검증하는 도구는 아닙니다.

PNG 프레임은 `src/characters/assets/akila/<상태>/`에 넣고 이름순으로 재생합니다. 상태는 `idle`, `smoking`, `speaking`, `drawing`, `firing`이며 파일 추가 후 앱과 미리보기를 다시 빌드하세요. 이미지가 없는 상태는 임시 화면을 표시합니다.

아킬라의 idle 상태에는 제공된 A형 SD PNG가 표시됩니다. 나머지 상태는 전용 이미지가 준비되기 전까지 플레이스홀더를 표시합니다. 기본 총기와 향후 사격 디자인 규칙은 제품 명세를 참조하세요.

Idle은 미세한 호흡과 간헐적인 담배 효과를 표시합니다. Smoking은 같은 기본 이미지에 짧은 불빛과 연기를 반복합니다. 시스템의 움직임 줄이기 설정을 따릅니다.

작업(Working) 상태는 기본 자세 위에 노트북과 작업 표시등을 표시합니다. 현재 원본의 양손은 주머니에 있어 노트북을 들거나 타이핑하는 손동작은 표현하지 않습니다. 자연스러운 손·팔 동작에는 별도의 일치하는 포즈 에셋이 필요합니다.

Working에서 다른 상태로 바꾸면 노트북이 닫히고 사라진 다음 새 상태를 표시합니다. 전환 중 다시 선택하면 마지막으로 고른 상태가 적용됩니다. 자연스러운 타이핑에는 주머니 손을 가린 몸통과 연결되는 소매·손 포즈 및 노트북을 받치는 레이어가 필요합니다.
