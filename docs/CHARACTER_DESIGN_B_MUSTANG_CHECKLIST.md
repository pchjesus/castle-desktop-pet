# B형 무스탕 — 디자인 계약 및 검수 체크리스트

**공식 기본 타깃:** B형 갈색/적갈색 무스탕. **A형:** 후속 선택 의상.

## 기준 원본
- `design/references/akila-sheet-01.png`: 첫 업로드 캐디. 앉은 포즈/표정/복장/리볼버.
- `design/references/akila-sheet-02.png`: 두 번째 업로드 캐디. 서 있는 전신/회전도/복장/리볼버·샷건.
- 기준 이미지들은 사용자가 직접 제공한 시트이며, 별도로 생성된 요약 인포그래픽과 혼동하지 않는다.

## 시각 점검
- [ ] 시트의 눈썹·선글라스·머리·수염·얼굴형이 동일
- [ ] 모발·얼굴·부츠의 기준 위치가 포즈 간 일관
- [ ] 적갈색 무스탕 가죽, 크림색 양털 칼라/소매, 검은 셔츠, 회색 바지, 검은 부츠
- [ ] 기본 Idle은 서 있는 무기 없는 자세(시트의 총 소지 포즈를 그대로 Idle로 오인 금지)
- [ ] 오른손으로 리볼버를 꺼내고 오른손으로 조준/사격/정리
- [ ] 얼굴/팔/총이 중간 프레임에서 뒤집히거나 갑자기 방향 바뀌지 않음
- [ ] 투명 PNG에 제목, 배경 건물, 명암 배경, 다른 캐릭터, 바닥 그림자가 섞이지 않음
- [ ] 1024x1600 RGBA, 기준 발 위치, 180/240/360px 프리뷰에 잘림 없음
- [ ] A형의 원본 11장 + 기존 Working, 단발, 쌍권총 재생 기능 보존
- [ ] 표정 시안의 '상처/피' 예시는 기본 평소 표정에 포함하지 않음
- [ ] Win10/11 GUI 실기기 검증 여부는 별도 표시

## 활성화 게이트
- Gate 0: 두 원본 캐디 그대로 커밋, 해시, 디자인 계약 작성
- Gate 1: B형 무스탕 **서 있는 Idle** 후보와 비교 이미지; 사용자 시각 승인 전까지 미승인
- Gate 2: B형 나머지 상태의 일관된 에셋 확보 및 전환 테스트
- Gate 3: B형 기본 활성화, A형 의상 옵션, 오프라인/윈도 빌드 및 시각 QA
