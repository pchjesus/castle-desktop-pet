# B형 무스탕 — 디자인 계약 및 검수 체크리스트

**공식 기본 타깃:** B형 갈색/적갈색 무스탕. **A형:** 후속 선택 의상.

## 현행 제작 기준 — 2026-11-06 사용자 재확정
- [**공식 시트 02**](../design/references/akila-sheet-02.png): 상단 중앙의 **큰 B형 서 있는 전신**을 머리/몸통/다리/부츠 비율과 그림체 기준으로 지정, 그 왼쪽의 **큰 앉은 B형**을 Sitting 기준으로 지정한다.
- [상세 원본 기준 계약](AKILA_CANONICAL_SHEET_02.md) 우선. 미니 턴어라운드는 자세/의상 방향용이며, 신체 비율을 큰 전신에 강요하지 않는다.
- 이전 `idle-gate1b-alpha-cleanup-unapproved.png` 및 초기 B 후보는 **이력용 미승인 기술 후보**. 신규 Idle 제작 시 이를 기준으로 머리를 키우거나 다리를 줄이면 실패.
- 시트의 B형 서 있는 모습은 리볼버를 들고 있으므로, **무기 없는 Idle**은 인체 비율·손 크기·작화 유지한 별도 편집 후보가 필요하다.
- 승인된 것은 **기준 시트의 선택**이다. 런타임 B형 PNG의 아트 승인이나 배포 승인은 아직 아님.

## 시각 점검
- [ ] 시트 02 B형 큰 전신의 눈썹·선글라스·머리·수염·얼굴형이 일관됨
- [ ] 모발·얼굴·부츠의 기준 위치가 포즈 간 일관
- [ ] 적갈색 무스탕 가죽, 크림색 양털 칼라/소매, 검은 셔츠, 회색 바지, 검은 부츠
- [ ] 기본 Idle은 서 있는 무기 없는 자세(현재 Idle에서 총을 든 자세를 기본으로 혼동하지 않음)
- [ ] Sitting은 시트 02의 큰 앉은 전신과 Idle의 얼굴·의상·머리/몸통 비례를 보존하는 독립 포즈로 제작
- [ ] 오른손으로 리볼버를 꺼내고 오른손으로 조준/사격/정리
- [ ] 얼굴/팔/총이 중간 프레임에서 뒤집히거나 갑자기 방향 바뀌지 않음
- [ ] 투명 PNG에 제목, 배경 건물, 명암 배경, 다른 캐릭터, 바닥 그림자가 섞이지 않음
- [ ] 시트 02 큰 B형 전신의 머리·몸통·다리 비례 보존(캔버스 크기를 맞추기 위해 인물만 세로로 늘리지 않음)
- [ ] 최종 앱 정렬용 투명 캔버스는 가급적 1024×1600 RGBA. 원본 소스가 1024×1536 등이어도 **인물 종횡비가 보존되도록 투명 여백으로 정렬**하며 치수만으로 미승인 처리하지 않음
- [ ] 실제 인물 경계·발 기준선 정렬, 알파 채널/광륜 품질, 180/240/360px 프리뷰에 잘림 없음
- [ ] A형의 원본 11장 + 기존 Working, 단발, 쌍권총 재생 기능 보존
- [ ] 표정 시안의 '상처/피' 예시는 기본 평소 표정에 포함하지 않음
- [ ] Win10/11 GUI 실기기 검증 여부는 별도 표시

## 활성화 게이트
- Gate 0: 사용자가 재확정한 시트 02를 공식 최상위 원본으로 등록(완료), 모든 후속 B PNG를 시트 02 기준으로 검토
- Gate 1: B형 무스탕 **서 있는 Idle** 후보와 비교 이미지; 사용자 시각 승인 전까지 미승인
- Gate 2: B형 나머지 상태의 일관된 에셋 확보 및 전환 테스트
- Gate 3: B형 기본 활성화, A형 의상 옵션, 오프라인/윈도 빌드 및 시각 QA
