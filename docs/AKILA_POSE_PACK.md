# Akila v0.3C — 전용 포즈 에셋 규격

## 왜 필요한가
기존 `idle/000.png`는 **양손이 주머니에 있는 한 장의 완성된 그림**이다. CSS 노트북·총기 오버레이만으로는 양팔과 손을 자연스럽게 꺼내거나 인체 연결을 보장할 수 없다. v0.3C의 시각적 완료 조건은 실제 전신 포즈 또는 정확히 합성된 몸통/팔 파생 에셋이다.

## 디자인 원본
- 기준: `src/characters/assets/akila/idle/000.png` (313×608 RGBA).
- 형태: 기존 A형 약 3등신 SD 비율·현재 얼굴/수염/머리/선글라스·입술에 문 담배와 복장 그대로 유지.
- 의상: 올리브색 재킷 밝은 어깨·소매 라인, 검은 셔츠, 회색 바지, 검은 군화.
- 같은 파일의 리페인트가 아니라 **고정된 얼굴·몸통 위에 팔과 소품만 다른 자세로 구성**한다.
- 원본 웹툰 컷은 저장소에 포함하지 않는다.

## 파일 인터페이스
```text
src/characters/assets/akila/
  idle/000.png                 # 승인 원본, 변경 금지
  working/000.png              # 노트북 지지 + 타이핑 기본
  working/001.png              # 손 타이핑 변형
  working/002.png              # 키 입력 휴식/화면 확인
  drawing/000.png              # 리볼버 꺼내기 시작
  drawing/001.png              # 리볼버 조준
  firing/000.png               # 리볼버 조준
  firing/001.png               # 리볼버 발사/반동
  firing/002.png               # 리볼버 내리기
  dual_firing/000.png          # 리볼버 + 두 번째 권총 꺼내기
  dual_firing/001.png          # 두 무기 조준
  dual_firing/002.png          # 교차 발사/반동 A
  dual_firing/003.png          # 교차 발사/반동 B
  dual_firing/004.png          # 총기 정리
```

각 PNG는 **같은 313:608 비율**, 투명 배경, 같은 캐릭터 규모/발 중심선/머리 위치로 내보낸다. 가능한 출력 크기: 기준 313×608 또는 고해상도 626×1216(모든 포즈에 일괄 적용). 폴더당 파일 이름은 000부터 오름차순이며, 프레임 수와 FPS는 구현 단계에서 조절한다. 최소 프레임을 제시한 것으로 최종 자연스러움에 필요한 중간 프레임은 추가할 수 있다.

## 시각 검수 필수조건
- 손이 주머니 안과 키보드/권총 양쪽에 **중복 노출되지 않는다**.
- 소매-팔-손이 몸에 연결되며, 무기와 노트북을 실제로 잡고 있다.
- 단독 firing: **리볼버** 1정; 실린더와 총열이 구별된다.
- dual_firing: **리볼버** 1정 + **글록형 반자동 권총** 1정. 두 무기가 서로 다르게 생겨야 한다.
- 총구 섬광·연기·탄피는 애니메이션 효과로 분리할 수 있다. 리볼버에는 자동권총 슬라이드/탄피 배출 모션 적용 금지.
- 원본과 동일한 SD 외형; 반실사화·체형 변화·얼굴 재생성 금지.
- 180/240/360px 미리보기에서 화상 잘림, 위치 이동, 부자연스러운 겹침 없음.

## 구현·테스트 인계
- 승인 PNG가 생성될 때까지 해당 상태는 **미구현**으로 표시한다.
- 상태별 이미지 로더를 사용하고, 액션은 단발 시퀀스로 재생하여 끝나면 Idle 복귀.
- Working 종료(노트북 닫기) 완료 뒤 사격 상태 전환, 마지막 요청 우선.
- 액션 연속 선택·중단·사이즈 변경·숨김·reduced-motion·타이머 해제를 테스트한다.
- Electron과 오프라인 `preview.html`은 **동일한 이미지·로직** 사용.
- 브라우저 스크린샷과 Windows 실행 결과를 별도로 명시.
