# B-13.1 integrated UX hotfix

Baseline: `abb2c88`, branch `feat/b-canonical-07-proportions`, Draft PR #11.

## Changes and evidence

- Pet surface: explicit transparent HTML before CSS/JS loads; native window is shown only after `ready-to-show`. B runtime holds the decoded previous pose until the next approved PNG is ready; no opaque fallback text/card is inserted. Official images, derived approvals, hashes, runtime mappings and the A/prototype boundary are unchanged. Diagnostics (`preview.html`) remains an intentionally opaque, separate review window.
- Speech: a sandboxed, non-focusing, always click-through transparent owned window beside the whole pet rectangle. This leaves the character's scale, window dimensions, feet anchor and saved position unchanged. Work-area coordinates support negative monitor origins, edges and size changes. The hidden speech renderer is prewarmed by the initial empty message to avoid first-dialogue window startup latency. Text is measured after wrapping and the window follows drag/resize/display changes, including programmatic Windows `move` events. 140ms fade in/out; no supplementary motion in Reduced Motion. The browser-only fallback is at the lower side; native speech never renders that fallback.
- Dynamic timing, manual and automatic: O-01 immediately → **1000ms** preparation → **1500ms** approved Dynamic pose → **850ms** aftermath → configured base. The readable speech lifetime is independent and may continue briefly after the pose returns. Automatic shooting cooldown starts at shot end, before the aftermath. User action, settings, hide/suspend and disposal invalidate both kinds of timers. B-13 weights, 5/6-click warning, dialogue registry, persistence and event contract are preserved.
- Pose presentation: decoded overlapping layers crossfade in 160ms. Idle/Smoking breathe by at most 0.15% vertically from the feet; Sitting/Drawing settle by 0.5px; Speaking keeps the exact seven approved images. Shots have one brief brightness/recoil accent (maximum 0.45px, no rotation), followed by stillness. Small glow accents are anchored to barrel/embedded flash coordinates measured from the approved Firing (1024×1600), Dual (1024×1536) and Dynamic (1004×1567) PNGs, with contain/letterbox offsets recalculated on resize. No new image, projectile, casing, joint animation, sound or dependency.

Confirmed code causes: Dynamic used `readableMs(text)` as the pre-shot delay; speech used a top-of-window 94%-wide rectangle; live rendering removed the old image before replacement decode. The supplied request describes a white Windows rectangle but does not include its screenshot in this checkout. Existing native transparency flags were already correct. First-paint and replacement gaps are repaired; browser alpha evidence alone cannot establish the original Windows compositor cause.
