# B-CANONICAL-05 검수 상태

Speaking 비교 화면은 7개 선택 시 실제 지정 이미지의 로드 완료와 naturalWidth를 확인한 뒤 다음 이미지를 선택한다. 요청 오류 배열은 계속 검사하며 ERR_ABORTED를 일괄 무시하지 않는다. 별도 브라우저 테스트에서 지연 이미지 요청 중단과 실제 누락 이미지 decode 실패를 재현한다.

시각 검수 의견은 사용자가 직접 입력한 값만 로컬 저장 및 JSON으로 내보내며 서버에 전송하지 않는다. 자동 테스트는 사용자의 시각 승인을 생성하지 않는다. 공식 원본/03/04 비교와 기존 상태·크기·배경·기준선을 유지한다.

기술 상태: Sitting 얼굴·눈높이 확인 필요, Firing Dynamic 배경/섬광 확인 필요, Dual Firing blocked, Speaking 머리카락/크롭 확인 필요, PNG 6종 저알파 외곽 확인 필요. Windows 실행파일 자동 시작과 실제 Windows 10/11 수동 GUI 검증은 별도다. GitHub API 접근 실패로 원격 로그·CI 결과 조회가 막힌 경우 이를 통과로 기록하지 않는다.

로컬 작업 당시 GitHub API는 `Forbidden`을 반환하여 실행 42326633143의 상세 로그와 42326633134의 아티팩트 내용을 직접 확인할 수 없었고, PR #6 설명 갱신도 실패했다. 이 문서는 확인된 로컬 검증과 미확인 상태를 기록한다. Windows CI 및 실기기 결과는 GitHub에서 별도 확인이 필요하다.
