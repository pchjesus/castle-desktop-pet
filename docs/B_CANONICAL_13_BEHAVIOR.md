# B-CANONICAL-13 — v1.7 행동·클릭·대사

기준 HEAD `723eb5d`. 승인 PNG와 해시, B-12의 9포즈 에셋 매핑은 변경하지 않았다. 기본 자세는 Smoking이며 설정으로 Idle을 선택한다. 실제 펫은 별도 행동 제어기가 모든 완료·중단·복귀를 소유한다. 검수 미리보기는 기본 시작을 Smoking으로 갱신했으며 개별 에셋의 기존 B-12 재생 검사는 유지한다.

## 구현된 규칙

- 시작·자동 행동 완료 후 120~180초 균등 무작위 대기. 반대 휴식 10, Sitting 18, Speaking 30, Drawing 12, Firing 18, Dual Firing 6, Dynamic 6 가중치.
- 자동 사격 완료 시 180~300초 쿨다운. 완료 전 사용자 중단도 그 시점을 사격 종료로 취급한다. 쿨다운 및 자동 사격 OFF에서는 세 사격을 제거한 뒤 나머지를 합계 1로 재정규화한다. 수동·명시적 이벤트 사격은 제한하지 않는다.
- Sitting·휴식 10~20초, Drawing 3~6초, Speaking 7×500ms(감소 동작 1초), Firing/Dynamic 1.5초, Dual 2.4초. 대사가 있으면 가독 시간까지 포즈를 유지한다. 수동 유지형 Idle/Smoking/Sitting/Working은 사용자 변경 전까지 유지한다. 기본 자세를 직접 선택하면 새로운 자동 대기를 시작한다.
- 대사 확률은 v1.7 제안 초기값을 사용한다. 일반 클릭은 50% 대사 또는 무언 반응. 클릭/희귀 대사도 ID별 쿨다운을 적용한다. 일반 대사는 120초, 희귀 대사는 30분 초기값이며, 적합한 후보가 소진되면 무언 반응한다. 출처 풀이 모두 가능할 때 원작 계열 30%/창작 70%. 본문 표시 시간은 `max(4초, 글자수×110ms+1.6초)`, 최대 16초다.
- O-01은 Dynamic **발사 전** 고정 표시한다. 이후 실제 사격 포즈를 실행한다. O-03~O-06은 개별 무작위 항목이다. O-08/O-15/C-12/C-13/C-16은 등록하지 않고 C-18은 비활성이다. O/C 레지스트리는 출처·승인 상태·행동·트리거·희귀도·쿨다운을 갖는다.
- 3초 이동 창 안에서 다섯 번째 왼쪽 클릭은 무언 Drawing 경고, 경고 중 다음 클릭은 확정 블랙맘바 대사다. 추가 클릭은 타이머를 재시작하지 않는다. 6px 이동부터 드래그이며 드래그·취소·오른쪽 클릭은 클릭 횟수로 세지 않는다. 무언 반응 종료가 3초 창의 클릭 기록을 지우지 않는다.
- 사용자 조작 > 이벤트 > 자율 행동. 수동 유지 중 이벤트는 거부한다. 이벤트끼리는 deploymentComplete > testPassed > jobStart다. 승인 이벤트 3종의 대사/순서는 내부 계약·테스트로만 제공하고 외부 연동은 추가하지 않았다.
- 페이지 숨김은 진행·대사 타이머를 폐기하고 기본 자세로 정리한다. 복귀 시 새 대기를 시작하며 누적 행동은 실행하지 않는다. 설정 변경은 진행 행동·클릭 경고를 정리하고 기본 자세를 적용한다. 창 종료는 행동·애니메이션 타이머를 폐기한다. 일반 창 포커스 이동은 숨김으로 취급하지 않아 메뉴를 열거나 다른 앱을 사용하는 동안 자율 기능을 불필요하게 중단하지 않는다.

## 설정·파일 경계

우클릭 메뉴의 기본 자세, 자율 행동, 자동 사격을 `%APPDATA%/castle-desktop-pet/behavior.json`에 저장한다. 파일 없음/손상 시 Smoking·ON·ON으로 복원한다. 설정 값은 allowlist로 정규화하며 메뉴 IPC는 기존 전용 창 송신자 검사를 유지한다. 새 이미지·사운드·의존성을 추가하지 않았다.

신규 모듈은 행동 타이머와 대사 데이터만 분리했다. 기존 창/입력 모듈의 전면 리팩터링은 하지 않았다. 변경 위험은 애니메이션 완료와 행동 완료의 소유권 충돌, 포인터의 클릭/드래그 오분류, 오래된 타이머 복귀다. 실제 펫은 managed 모드로 애니메이션의 하드코딩된 Idle 복귀를 차단하고 제어기의 세대 번호와 타이머 정리로 이전 행동을 취소한다. 이미지 알파 히트 테스트·우클릭·드래그 위치·창 크기·대사는 기존 경로를 유지한다.

B-14 전체 상태창·도감·빈도 확장 설정, B-15 외부 Codex 연동은 미구현 범위다. 일반 미리보기의 B-12 에셋 검사와 실제 펫 행동 검사는 별도로 실행한다.

## 검증 결과

- 빌드 및 Node 테스트 65개 통과. 가상 시간으로 가중치/재정규화·120~180초 범위·종료 후 사격 쿨다운·수동 우회·기본 자세 복귀·수동 유지·O-01 선출력·5/6회 클릭·불균등 클릭 간격·숨김/복귀·폐기·설정 파일 저장/손상 복구를 확인했다.
- 기존 B-12 브라우저 QA 81개 통과. 실제 펫 렌더러 브라우저에서는 기본 Smoking, 진짜 마우스 5/6클릭·연타 차단·드래그 분리, 수동 Working 유지, 자연 종료 시 설정 Idle 복귀, 자동 사격 OFF에서도 수동 Dynamic/O-01/Smoking 복귀, 메뉴 설정 명령을 확인했다. [보고서](b13-behavior/report.json), [블랙맘바 표시](b13-behavior/blackmamba.png), [메뉴](b13-behavior/menu.png).
- 공식 원본 9종 해시와 승인 이미지 등록/파일은 보존했다. 기존 창 크기/alpha hit test/전용 메뉴 IPC 검사도 유지했다.
- 실제 Windows 수동 GUI는 수행하지 않았다. Windows smoke에는 발사 전 가독 시간에 맞는 대기 상한을 반영했다. GitHub API `api.github.com/graphql`이 403으로 차단되어 원격 CI/Windows smoke 결과를 조회할 수 없었다. 로컬 브라우저 검증을 Windows 통과로 기록하지 않는다.

실제 펫의 수동 행동 전환은 이전 완료 콜백을 취소하고 즉시 전환한다. 이미지 검수 미리보기는 B-12의 독립 포즈 검사용으로 기존 전환 경로를 유지한다. 이 경계는 향후 공통 행동 변경 시 재검토한다.

O-13은 승인된 문구를 보존하되 반복 오류 문맥 후보로만 등록하여 자율 일반 대사에서는 제외했다. deploymentComplete는 중복 대사 레코드 없이 O-10을 직접 참조한다.

OS suspend/resume 신호를 전달하며, 타이머가 예정 시각보다 5초 이상 늦게 실행되면 이전 행동을 실행하지 않고 새 대기로 정리한다. 설정 변경 중에도 유효한 사격 쿨다운은 보존한다.
