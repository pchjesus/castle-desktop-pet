# 아킬라 B형 무스탕 디자인 기준

공식 기본형 목표는 B형, 현재 실행형은 A형이다. 사용자 제공 [첫 시트](../design/references/akila-sheet-01.png)는 앉은 자세·표정·리볼버 및 동작, [두 번째 시트](../design/references/akila-sheet-02.png)는 중앙 B형 서 있는 전신과 오른쪽 4방향을 기준으로 한다. 앉은 자세는 기본 Idle의 비례 기준이 아니다.

두 의상 모두 진갈색으로 뒤로 넘긴 머리와 이마선, 짙은 수염, 갈색 틴트 에비에이터 선글라스, 진지한 표정과 동일한 SD 얼굴·몸·손 비율을 유지한다. B는 적갈색 가죽 무스탕과 크림 양털 옷깃·소매, 검은 셔츠, 회색 바지, 벨트, 검은 부츠다. A는 올리브 블루종과 밝은 소매 라인이다. 근사 색상 기준: 가죽 #8a4934, 양털 #ddbc98, 셔츠 #1d1b1b, 바지 #514b50, 부츠 #181719. 실제 시트의 명암과 색을 우선한다.

무기 없는 전신 Idle은 발끝·머리가 잘리지 않고 투명 RGBA, 일관된 발 기준선, 자연스러운 손과 소매, 담배, 그림체를 갖춰야 한다. 원본 시트의 문자·배경·그림자가 포함되거나 중복 손, 무기가 있는 후보는 승인하지 않는다. 목표 캔버스는 1024×1600이며 180/240/360px에서 검사한다.

단발 리볼버는 캐릭터 자신의 **오른손**으로 꺼내고 조준·사격·정리한다. 정면일 때 캐릭터 오른손은 화면 왼쪽이다. 실린더·총열·손잡이를 구분한다. 쌍권총은 리볼버와 반자동 권총 각 1정이다. Working은 노트북과 양손의 접촉, Smoking은 입의 담배를 유지한다. Speaking·Drawing·Firing·Dual Firing의 표정과 무기는 첫 시트의 표정 및 리볼버를 참조한다. 두 번째 시트의 앉기와 샷건은 미래 참조이며 이번 기능이 아니다.
