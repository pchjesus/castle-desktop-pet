공식 기본형 목표는 B형, 현재 실행형은 A형이다. 과거 [첫 시트](../design/references/akila-sheet-01.png)와 [두 번째 시트](../design/references/akila-sheet-02.png)는 현재 제작의 시각 기준에서 **퇴역**했으며, 필요 시 이력 확인에만 사용한다. 앞으로는 **현재 작업 마스터 후보 및 향후 승인된 후속 무스탕 이미지**를 기준으로 한다.

두 의상 모두 진갈색으로 뒤로 넘긴 머리와 이마선, 짙은 수염, 갈색 틴트 에비에이터 선글라스, 진지한 표정과 동일한 SD 얼굴·몸·손 비율을 유지한다. B는 적갈색 가죽 무스탕과 크림 양털 옷깃·소매, 검은 셔츠, 회색 바지, 벨트, 검은 부츠다. A는 올리브 블루종과 밝은 소매 라인이다. 근사 색상 기준: 가죽 #8a4934, 양털 #ddbc98, 셔츠 #1d1b1b, 바지 #514b50, 부츠 #181719. 현재 무스탕 작업 이미지의 명암과 색을 우선한다.

무기 없는 전신 Idle은 발끝·머리가 잘리지 않고 투명 RGBA, 일관된 발 기준선, 자연스러운 손과 소매, 그림체를 갖춰야 한다. 원본 시트의 문자·배경·그림자가 포함되거나 중복 손, 무기가 있는 후보는 승인하지 않는다. 렌더러와 기존 에셋의 일관성을 위해 최종 정렬용 **투명 캔버스는 1024×1600을 권장**하고 180/240/360px에서 확인한다. 단, **이는 캐릭터 체형의 가로세로 비율을 지정한 것이 아니다.** 서 있는 캐릭터의 실제 외형·머리·몸통·다리 비례는 현재 무스탕 작업 이미지 계열을 우선하며, 1024×1536 또는 다른 비율의 원본 소스도 투명 여백 추가·비례 보존형 배치로 정렬할 수 있다. 인물 자체의 가로/세로를 서로 다른 배율로 늘리거나 줄이는 것은 금지한다. 이미지 내부의 실제 인물 경계와 발 기준 좌표를 측정하여 포즈 간 일관성을 확보한다.

단발 리볼버는 캐릭터 자신의 **오른손**으로 꺼내고 조준·사격·정리한다. 정면일 때 캐릭터 오른손은 화면 왼쪽이다. 실린더·총열·손잡이를 구분한다. 쌍권총은 리볼버와 반자동 권총 각 1정이다. Working은 노트북과 양손의 접촉, Smoking은 입의 담배를 유지한다. Speaking·Drawing·Firing·Dual Firing의 표정과 무기는 **현재 무스탕 작업 이미지 및 그로부터 승인된 후속 포즈**를 우선한다. Sitting(앉은 자세)은 B형 포즈 제작 단계에 포함하고, 샷건만 후속 확장으로 남긴다.

## Gate 1 후보 검수
새 후보 `src/characters/candidates/akila_mustang/idle-gate1-unapproved.png`는 1024×1536 RGBA이며 광륜이 남고 불투명 영역을 확보하지 못해 **투명 에셋 품질 기준**을 통과하지 못했다. 1024×1536이라는 원본 캔버스 크기 자체는 불합격 사유가 아니다. 인물만의 정확한 머리·발 기준 좌표는 광륜 제거 후 재측정해야 하며 현 단계에서 확정하지 않는다. 머리 크기, 몸통·다리 길이, 재킷 양털, 손과 부츠는 **현재 작업 중인 무스탕 이미지 계열**과의 일관성으로 평가해야 한다. 180/240/360px 비교 자료는 `design/mustang-gate1-review.html`이다. 후보는 실행에 사용하지 않는다.
