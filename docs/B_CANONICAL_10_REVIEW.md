# B-CANONICAL-10 — 미완성 검수 후보

공식 원본 9종과 사용자 승인 파생본 3종은 그대로 보존했다. `cleanup-v10`은 런타임에 등록되지 않는 신규 편집 시안이며 `manifest.json`에 파일별 SHA-256과 문제점을 기록한다.

Dual Firing 원본의 한쪽 총은 자동권총 형태이며, 원본 무기 형태 보존을 우선했다. 배경 제거를 두 차례 편집했다. 이미지 뷰어에서 RGB 채널의 배경을 보고 실패로 오판했으나, 실제 브라우저 밝은 배경 합성에서 배경이 제거된 것을 확인했다. Firing Dynamic도 합성 결과에서 배경 제거와 좁은 섬광 형태를 확인했다. RGB 채널만 보고 섬광 형태나 배경 잔여를 판단하지 않는다. 두 시안 모두 손·총·탄피·섬광 및 선화가 재묘사되어 원본 세부 동일성과 경계 품질에 대한 최종 승인은 미완료다.

Speaking은 승인 Idle과 공식 표정 시트의 위쪽 7컷을 함께 참조하여 각각 전신 편집했다. 단순 얼굴 붙여넣기를 하지 않았지만 모델의 재묘사로 얼굴·목·어깨·몸통 및 프레임 정렬의 동일성을 보장하지 못한다. 사용자 승인 Idle 자체는 수정하지 않았다. 새 7컷은 애니메이션 제작 완료가 아닌 검수 시안이며 필요 시 작가의 국소 재작화와 프레임 정합 작업이 필요하다.

미리보기의 B-CANONICAL-10에서 원본 / 04 / 10 후보를 180·240·360px, 밝음·어두움·격자 배경으로 비교한다. Speaking 표정을 개별 선택하거나 재생·정지할 수 있다. 탭 숨김 시 정지하며 Reduced Motion에서는 자동 재생하지 않는다. 공식 표정 원본은 시트 전체, 04는 얼굴 크롭, 10은 전신이므로 같은 표시 영역에서 보이더라도 같은 얼굴 배율의 정밀 비교는 아니다.

모든 후보는 미완성이며 기본 펫의 미승인 포즈 차단을 유지한다. 정식 배포 또는 main 병합은 하지 않는다. 검수 화면 추가 외 런타임 리팩터링은 불필요하다.

검증: 빌드 및 Node 테스트 47개, 기존 브라우저 QA 79개 통과. 신규 QA는 9이미지 × 3크기 × 3배경의 81조합 로딩/크기 조작과 Speaking 7단계 연속 재생·정지를 확인했다. 180/360px의 세 배경 스크린샷은 `artifacts/b10`에 생성된다.
