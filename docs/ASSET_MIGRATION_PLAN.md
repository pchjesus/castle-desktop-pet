# B형 에셋 전환 계획

**공식 기준:** [캐릭터 시트 02](../design/references/akila-sheet-02.png)의 **큰 B형 무스탕 서 있는 전신과 앉은 전신**, 상세한 제약은 [시트 02 계약](AKILA_CANONICAL_SHEET_02.md). 기존 'Gate1B 정제본을 마스터로 삼고 시트를 퇴역' 정책은 폐기한다. 기존 `idle-gate1b-alpha-cleanup-unapproved.png`는 기술적 실험 이력이며 기준 원본이 아니다. **시트와 후보 비율이 다르면 후보가 잘못된 것**이다. 초기 PNG/스크립트/동작은 삭제하지 않는다.

현재 런타임은 A형 유지, B형 상태가 완성되기 전 A/B 이미지를 한 애니메이션에서 섞지 않는다. 시트 02 서 있는 포즈는 손에 리볼버가 있으므로, Idle 스프라이트 제작 시 얼굴·신체 비율을 유지한 채 무기 없는 손을 별도로 정리해야 한다. Sitting도 원본의 앉은 큰 전신 비율을 사용한다. 미니 턴어라운드의 더 짧은 체형을 확대 적용하지 않는다.

| 상태 | 필요한 B형 포즈·전환 | 현재 |
|---|---|---|
| idle | 무기 없는 서 있는 전신, 일정한 머리·발 기준 | 후보 검수 |
| sitting (pose) | 시트 02의 큰 무스탕 서 있는 전신과 같은 얼굴·의상·인체 비례의 앉은 자세. 별도 런타임 상태 추가는 앱 통합 단계에서 결정 | 미구현 |
| smoking | idle에서 담배 불빛·연기로 진입하고 복귀 | 미구현 |
| speaking | 무표정 기준 발화·종료 포즈 | 미구현 |
| working | 노트북 등장·타이핑·닫기와 양손 연결, idle 복귀 | 미구현 |
| drawing | 오른손으로 리볼버를 꺼내 조준 유지 | 미구현 |
| firing | 오른손 조준·발사·반동·정리, idle 복귀 | 미구현 |
| dual_firing | 리볼버와 반자동 권총 양손 조준·교차 사격·정리 | 미구현 |

7개 기본 상태와 Sitting 포즈가 일관성을 만족하고 크기별·브라우저·Windows 검증을 통과한 뒤에만 기본 실행을 B로 전환한다. 준비되지 않은 상태를 A형으로 대체하지 않는다. A형은 별도 에셋과 실행 설정을 보존하여 복구한다. Sitting은 이번 B형 포즈 제작 단계에 포함한다. Shotgun은 후속 확장이다.
