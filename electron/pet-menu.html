왼쪽 클릭: 아킬라의 짧은 반응을 확인해요. 연속 5회 클릭은 무언 경고, 6회째는 특별 대사예요.

드래그: 캐릭터를 이동해요. 우클릭: 이 메뉴를 열어요.

동작 탭: 특정 동작을 수동 실행해요. 서 있기·앉기·작업은 일정 시간 뒤 평소 자세로 돌아오며 자동 행동이 다시 시작돼요.

기본/빈도: 평소 자세와 자동 행동·대사 간격, 자동 사격 쿨다운을 각각 1~15분으로 설정해요. 기존 랜덤 범위는 슬라이더 조절 후 지정 분 간격으로 바뀌어요.

‘행동별 등장 빈도’의 비중은 별개로 0~40까지 조절할 수 있어요. 0이면 자동에서만 제외하고 수동 동작은 유지돼요.

숨기기·일시 중단 뒤에는 보류된 동작을 한꺼번에 재생하지 않아요.

더보기 → 현재 상태에서 세 가지 Codex 이벤트를 직접 시험할 수 있어요. 테스트 버튼은 실제 Codex 연결이나 테스트·배포 성공을 증명하지 않아요.

더보기 → 현재 상태의 스위치를 오른쪽으로 밀면 로컬 Codex 훅을 설치하고 왼쪽으로 밀면 해제해요. 기존 설정을 보존하며, 로컬 Codex의 /hooks에서 실제 실행을 승인해야 해요. Node.js가 설치돼 있어야 훅이 동작해요.

클라우드에서 실행되는 Codex는 Windows 로컬 파일에 접근하지 못할 수 있어요. 설치 여부와 실제 이벤트 수신은 다르며, 테스트/배포 성공은 추측하지 않아요. 추가 AI API 호출은 없어요.
