기본/빈도: 평소 자세, 자동 움직임·대사·사격을 각각 설정해요. 대사 간격은 사격 쿨다운과 별개예요.

숨기기·일시 중단 뒤에는 보류된 동작을 한꺼번에 재생하지 않아요.

더보기 → 현재 상태에서 세 가지 Codex 이벤트를 직접 시험할 수 있어요. 테스트 버튼은 실제 Codex 연결이나 테스트·배포 성공을 증명하지 않아요.

외부 Codex 훅 또는 검증 스크립트에서 로컬 이벤트 파일에 기록하면 펫이 감지해요. API 호출이나 추가 AI 비용은 없어요. 자세한 연결 방법은 저장소의 B-15 가이드에서 확인할 수 있어요.
