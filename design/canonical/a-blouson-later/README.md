# Later A — Blouson (user-approved design reference)
This folder preserves the later A outfit from the 2026-11-06 A/B design sheet. It is **NOT** the very first prototype.
`approved_reference_sheet.png` is a byte-exact copy of the already tracked `design/references/akila-sheet-02.png` Git blob, containing the later A blouson as well as B design context.
There is no validated standalone transparent later-A frame pack yet. Do not use the archived first-prototype sprites as later A. Later B is the current default QA runtime. When later-A extraction is produced, preserve this reference unchanged and place new masks/derivatives in separately named paths with clear visual review status.
